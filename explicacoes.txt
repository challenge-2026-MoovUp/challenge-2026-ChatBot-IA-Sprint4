1. Origem dos dados

Os dados foram criados em Python para montar uma base fictícia de usuários da MoovUp. Como não foi disponibilizada uma base real de usuários, foram utilizados dados sintéticos para representar situações que poderiam acontecer dentro da plataforma.

O arquivo utilizado foi `base_moovup_500_usuarios.csv`.

2. Significado dos dados

- `id_usuario`: identificador de cada usuário.
- `idade`: idade do usuário.
- `regiao`: região onde o usuário está localizado.
- `transporte_principal`: principal meio de transporte utilizado.
- `frequencia_uso_semana`: quantidade de vezes que utiliza o transporte durante a semana.
- `pontos_acumulados`: quantidade de pontos acumulados.
- `pontos_resgatados`: quantidade de pontos já utilizados.
- `bilhetes_resgatados`: quantidade de bilhetes resgatados.
- `acoes_realizadas`: quantidade de ações realizadas dentro da plataforma.
- `pontuacao_engajamento`: pontuação que representa o engajamento do usuário.
- `nivel_engajamento`: classificação do usuário em Baixo, Médio ou Alto.

3. Quantidade e qualidade dos dados

A base possui 500 registros e 11 colunas.

Na validação inicial, não foram encontrados valores vazios nem registros duplicados.

Os dados foram utilizados para treinar e testar os modelos de Machine Learning.

4. Modelo 1 — Classificação

Foi desenvolvido um modelo utilizando o algoritmo Random Forest Classifier.

Seu objetivo é prever o nível de engajamento dos usuários, classificando-os em três categorias: Baixo, Médio e Alto.

O modelo apresentou 82% de acurácia nos dados de teste.

A categoria Alto apresentou o melhor F1-score, com 0,90. A categoria Médio apresentou maior dificuldade de classificação, com F1-score de 0,71.

5. Modelo 2 — Regressão

Foi desenvolvido um modelo para estimar a quantidade de pontos acumulados pelos usuários.

Foram testados três algoritmos: Random Forest, Extra Trees e Gradient Boosting.

O melhor resultado foi obtido pelo Gradient Boosting, com os seguintes resultados:

- MAE: 348,39 pontos.
- RMSE: 407,49 pontos.
- R²: -0,0477.

Apesar de apresentar o melhor resultado entre os algoritmos testados, o R² negativo demonstra que o modelo ainda possui limitações para realizar previsões precisas.

6. Análise dos resultados

O modelo de classificação apresentou um resultado satisfatório, alcançando 82% de acurácia.

Já o modelo de regressão apresentou dificuldades para estimar os pontos acumulados. A análise dos dados mostrou baixa correlação entre as variáveis disponíveis e os pontos acumulados.

Entre as variáveis analisadas pelo Gradient Boosting, pontos resgatados, idade e ações realizadas apresentaram maior importância para as previsões.

Como melhoria futura, seria interessante ampliar a base de dados e incluir informações mais relacionadas ao acúmulo de pontos.

7. API REST

Foi desenvolvida uma API utilizando Python e Flask para disponibilizar o modelo de classificação.

A API possui duas rotas principais:

- `/`: verifica se a API está funcionando.
- `/predict`: recebe informações de um usuário em formato JSON e retorna o nível de engajamento previsto pelo modelo.

A API foi testada com sucesso, recebendo os dados e retornando uma previsão de engajamento.

### 8. Objetivo final

O objetivo da MoovUp AI é utilizar Machine Learning para analisar o comportamento dos usuários, identificar seus níveis de engajamento e estimar seus pontos acumulados.

O projeto demonstra a aplicação de modelos de classificação e regressão, além da disponibilização de um modelo por meio de uma API REST.
